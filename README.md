# Hasard Lab

Simulateur de probabilités en français : un dé ou somme de deux dés, séries de 1 à 10 000 lancers, fréquences observées et probabilités théoriques.

## Utilisation

Ouvrir `index.html` dans un navigateur, avec `style.css` et `app.js` dans le même dossier. Aucune installation nécessaire.

## Publication GitHub Pages

Dans Settings → Pages, choisir Deploy from a branch, puis main et / (root), et cliquer sur Save.

Adresse prévue après déploiement : https://tigreoslam23.github.io/Simulateur-probabilites/
